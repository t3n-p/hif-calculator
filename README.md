# 学マス H.I.F 評価値計算機

学園アイドルマスターの H.I.F（初星アイドルフェスティバル）シナリオ用の評価値計算機です。Pアイドルを選び、各日のスケジュールと行動回数を入力すると、評価値が最も高くなる6枚のサポートカード編成（所持5枚＋レンタル1枚）を探索したり、指定した編成の評価値を計算したりできます。

## 使い方

`index.html` をブラウザで開くだけです。サーバーやアカウントは不要です。

- Pアイドルとメモリーを選び、スケジュール・試験・回数を入力します。
- 所持サポカ登録タブで自分の所持サポートカードと凸数を登録します。
- サポートカード設定タブで編成条件（SP率アップを持つ枚数など）を決め、固定・除外を指定します。
- 下部のバーから「編成を探索」を押すと、計算結果タブに上位10件の編成が表示されます。

所持サポカと各種設定は、開いた人のブラウザ（localStorage）に保存されます。使う人ごとに別々に保存されるので、他の人のデータと混ざることはありません。

保存・読み込みタブでは、所持サポカ登録とその他の設定をそれぞれ名前を付けてブラウザに保存したり、ファイル（JSON）に書き出してバックアップや別のブラウザへ移したりできます。

## データについて

- Pアイドル160枚（SSR122・SR13・R25）、サポートカード215枚のデータを内蔵しています。
- スケジュールとルールは seesaawiki の H.I.F ページ（https://seesaawiki.jp/gakumasu/d/H%2eI%2eF）を正としています。
- 評価値の計算式：(Vo + Da + Vi) × 2 + floor(スター性 × 7.5) + 10900（選抜試験R1/R2は最大換算で固定）。
